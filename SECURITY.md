# Security policy

Only the latest tagged release is supported.

Do not open a public issue for a vulnerability or attach a real Meshtastic `.cfg` file. Use GitHub's private vulnerability reporting for this repository. Remove credentials, cryptographic keys, names, identifiers, and exact coordinates from any reproduction.

The application is intentionally client-side. Its documented outbound requests are OpenStreetMap tiles and explicit Kartverket/geolocation-assisted lookups. It has no application backend, accounts, analytics, or telemetry.
